Predicting features without predicting pixels

The original model predicts a later scan's representation. This avoids reconstructing every image intensity, but it does not automatically produce useful disease dynamics.

The JEPA idea

A joint-embedding predictive architecture, abbreviated JEPA, learns to predict a target representation from a context representation. The original image-based I-JEPA paper predicts representations of target image regions from other regions. This repository adapts the general idea to longitudinal MRI visits. The image paper does not independently validate the temporal medical adaptation.

The historical pipeline encodes available MRI sequences with BRAINIAC, combines their features with clinical information under the stated configuration, summarizes the observed history, and predicts the next representation. A transformer is a neural architecture that combines information across tokens through attention. A token is one vector presented to that architecture. Here, visit tokens summarize a patient's sequence of observations.

The slowly moving teacher

An exponential moving average, or EMA, updates a target network as a weighted average of its old weights and the current online weights. The online network receives ordinary training updates; the target network changes more slowly. A projector maps encoder features into the space used by the loss.

Target weights ← m × old target weights + (1 − m) × online weightsThe momentum m is close to one. This is a training mechanism, not an uncertainty estimate or a guarantee of meaningful features.

The historical loss compares normalized vectors using cosine error. Cosine similarity measures how similarly two vectors point, independent of their lengths; cosine error is one minus that similarity. A low cosine error does not imply that a clinically important volume, boundary, or treatment effect is predicted accurately.

Collapse and implementation checks

Collapse occurs when different inputs produce nearly identical features. A collapsed representation may make a training objective easy while discarding the differences we care about. Feature standard deviation measures variation. Effective rank summarizes how many directions of variation are represented. Healthy values are useful diagnostics, not downstream success criteria.

Automatic mixed precision, or AMP, uses lower-precision arithmetic for parts of training. It saves memory but can overflow in large reductions. A gradient describes how a loss changes with a parameter or input. Checking gradient flow can verify that intended components receive a learning signal and future inputs do not influence a prediction. Gradient accumulation adds gradients from several passes before an optimizer update. It changes the effective update batch without requiring all images to be held in memory at once.

Time encoding is part of the model contract

Giving each visit its previous gap is not the same as giving it elapsed time from the start of the history. Equal-gap tokens can leave chronological order ambiguous. The later methodology-validity audit, recorded as R34, introduced a separately declared elapsed-time option and checkpoint compatibility checks. Matching saved tensor shapes does not establish matching time semantics.

The default JEPA loss was also found to update the backbone's LoRA parameters and predictor, but not the online projector. That is a documented property of this implementation. It is not a general rule for every JEPA, and repairing or changing it would be a separate experiment.

See chronology and projection semantics, the model implementation, and the original I-JEPA paper. The handbook does not infer useful forecasting from healthy monitors or finite gradients.
