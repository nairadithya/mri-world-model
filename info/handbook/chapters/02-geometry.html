Why coordinates come before models

A mask can have the right shape in memory and still lie over the wrong part of the brain. Array compatibility is not anatomical compatibility.

A three-dimensional image is stored as an array of voxels, the volume equivalents of pixels. Array indices such as (i, j, k) locate a value in memory. They do not tell us where that value lies in physical space.

The affine is the map, not the territory

An affine is a matrix mapping voxel indices into a declared physical coordinate system. It encodes orientation, spacing, and position. NIfTI, a common medical-image format, stores image data and header information that can supply this mapping. The physical units must be inspected rather than assumed.

[x, y, z, 1]T = A [i, j, k, 1]TA maps an array location into a physical location. Matching array dimensions does not imply matching A.

If the spatial part of the affine is measured in millimeters, the physical volume of one voxel is the absolute determinant of its upper-left three-by-three matrix. For an orthogonal grid, this is the product of the three voxel spacings. Native mask volume is the number of included voxels multiplied by that voxel volume.

Registration, resampling, and resizing

Registration estimates a transformation that aligns images. Resampling evaluates an image on a new grid using a coordinate mapping and interpolation. Resizing changes array dimensions. These operations are related, but they are not interchangeable.

The BRAINIAC input contract includes correction for smoothly varying intensity bias, physical resampling, optional registration when a template is supplied, removal of nonbrain tissue, a final resize to 96 voxels on each axis, and intensity normalization. A 96-cubed input contains 884,736 locations. It does not follow that each of those locations represents one cubic millimeter.

Masks use nearest-neighbor interpolation when aligned to a grid so that interpolation does not invent fractional class labels. Images can use different interpolation rules. Independently resizing an image and a mask as arrays can discard the coordinate relationship between them. The repaired project pipeline aligns masks through verified physical grids before the final resize.

Several kinds of correctness

  1. File correctness. The array loads, and its values are finite.
  2. Geometric correctness. The declared physical map is valid, and image and mask grids are aligned.
  3. Measurement correctness. Native volume arithmetic and label mappings are consistent.
  4. Target validity. The mask accurately represents the intended anatomy, consistently across visits and cohorts.
  5. Biological interpretation. An observed difference corresponds to the disease process of interest.

Passing an earlier level does not establish the next. An affine does not prove registration accuracy. A plausible overlay does not establish repeatability. Repeatability means that repeated measurement of the same underlying state gives sufficiently similar results.

Missing is not empty

An absent MRI sequence requires an explicit availability indicator. A nonfinite value, often called NaN, is not a valid observation. A missing mask is not a measured zero-volume compartment. Conversely, a genuinely empty compartment is a real zero that should remain in the evaluation. Excluding difficult empty cases after seeing predictions would change the question being answered.

See the preprocessing and geometry contract, missing and zero-volume rules, and NiBabel's coordinate-system documentation. The calculation for 96 cubed is explanatory arithmetic, not an empirical finding.
