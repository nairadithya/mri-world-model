What a representation is, and how to test one

A representation is an intermediate numerical description of an image. The important question is not whether it exists, but which useful information it preserves.

An encoder is a function, commonly a neural network, that converts an image into numerical features. We write those features as z = f(x). A latent representation is another name for those internal features. A vector stores a list of numbers; a spatial feature map retains a grid of feature vectors.

A decoder maps features back to an output such as a segmentation. A head is an output component for a particular task. A readout extracts a quantity from features. A probe is a readout used to investigate what the representation makes accessible.

Learning, supervision, and loss

Neural networks contain adjustable parameters, also called weights. A loss assigns a numerical penalty to an incorrect training output. Gradient descent changes parameters in directions intended to reduce that loss. An optimizer implements the update rule. One epoch is one pass through the scheduled training data.

Supervision is the target information supplied during training. A single volume per compartment is scalar supervision. A mask supplies a target at many image locations and is called dense supervision. A model receiving dense masks has more task-specific supervision than one receiving only volumes. A comparison between them cannot attribute an improvement to architecture alone.

Mask supervision does not imply mask input at inference. A model can learn from masks during training and receive only MRI when used. This distinction is essential for the R35 and R36 studies discussed later.

Pretrained, adapted, and frozen

A pretrained encoder starts from weights learned before the current experiment. Fine-tuning adapts those weights to the new task. A frozen encoder keeps its weights unchanged while a readout is fitted. These are different fitting budgets, not interchangeable labels for one method.

LoRA, low-rank adaptation, learns a constrained update to a pretrained weight matrix while keeping the original matrix fixed. It reduces the number of trainable parameters. It does not guarantee good MRI features or a successful temporal model. The historical project adapted BRAINIAC, a pretrained MRI backbone, through LoRA.

Why readout capacity matters

A linear readout applies weighted sums to features. A nonlinear readout can combine features in more complicated ways. A multilayer perceptron, or MLP, is a feed-forward neural network and is one nonlinear option. Better predictions from a larger readout can result from better decoding rather than a better representation.

Ridge regression is a linear model penalized for large coefficients. Its regularization strength controls how strongly that penalty acts. This matters when feature vectors have many dimensions but the number of independent patients is small. Selecting that strength must use training data or internal validation, not the evaluation outcomes.

A narrow probe is not an oracle

Failure of a linear probe does not prove that information is absent from the encoder. It means the stated fitting recipe did not extract the intended gain. Conversely, a powerful decoder's success does not establish general-purpose encoder quality.
