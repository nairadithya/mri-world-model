## Pre-fitting choices

- **Primary E condition.** Use `gaussian_observation` with the fixed 0.05 native-log-volume observation standard deviation. This matches the original observation-floor rationale and the other probabilistic arms. The earlier E ablation is already known, so this is not a blinded or untouched prespecification. Its assessment scores do not select the condition. The discrete condition remains the separately reported ablation companion. Keep exactly five primary H contrasts and the existing two-sided 99% Bonferroni intervals. This lock requires independent review before fitting.
- **Historical timing.** The adapter uses positive differences of the cohort's encoded week bins times seven days, with suffixes determining order only. These are approximate historical gaps, not verified exact scan dates. Invalid retained histories are excluded without bridging unusable visits. No future gap enters a predictor. Full-pilot review must assess this declared limitation rather than import the E-only timing approval as full-pilot approval.
- **Image reconstruction.** Reconstruct the original prepared input convention using the existing runtime transform and float16 storage round-trip. All final pooled features and frozen-head volumes must reproduce the existing original-checkpoint cache within fixed absolute and relative tolerances of 1e-4 before predictor fitting. Do not loosen the tolerances after a failure. Bind the actual MRI bytes and cache content.
- **Source normalization.** Fit channel means and population standard deviations using unique prepared source52 visits only, with a numerical standard-deviation floor of 1e-6. Validation and assessment visits do not fit normalization.
- **Neural sampling.** For each predictor seed, save twenty source-example orders sampled with replacement using equal-patient weights. H/L/G use identical orders, initialization and update counts. The unweighted stochastic loss therefore estimates the patient-uniform objective; do not weight it a second time. Select the earliest minimum uncalibrated validation CRPS epoch, then select the scalar uncertainty multiplier on validation only.
- **Ridge fitting.** Fit the shared voxelwise residual with equal-patient, mean-voxel squared loss. Use fold-training design centering/scaling and an unpenalized intercept. Three patient-grouped source folds select alpha from the existing six-value grid. CV predictive noise uses each fold's training residuals, never held-fold response fitting. Final anatomical residual RMS uses the selected-alpha out-of-fold source predictions. Validation selects only the existing scalar uncertainty multiplier. Retain coefficients, folds and out-of-fold predictions.
- **Numerics and artifacts.** Use float32 neural/encoder calculations without AMP or TF32; use float64 ridge moments. Retain selected and final weights, optimizer-bearing final checkpoints, private predictions, normalization, sampling orders, configuration, source hashes and resource receipts. Do not average seed predictions into an ensemble for scoring.

These implementation choices refine execution of the selected question; they do not authorize a changed success criterion. Independent implementation review, executed rejection tests and a content-bound run contract precede fitting. Independent aggregate-result review precedes any scientific success claim. Computational completion alone is not scientific acceptance.
