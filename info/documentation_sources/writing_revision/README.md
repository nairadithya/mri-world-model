# Plain-English writing revision

This revision answers the request to make the four drafts clear to a reader with a reasonable grasp of English. It changes wording and organization, not the research task or reported outcomes.

## Document roles

Each document has one main role:

- `TODO.md` lists the steps left at the archived research snapshot. It does not authorize execution.
- `EXPERIMENTS.md` records measurements, corrections, withdrawals, and limits. Tables separate values that previously appeared as slash-separated sequences.
- `METHODS.md` defines terms and protocols. It also contains the historical decision, proposal, and audit indexes moved from Notes.
- `NOTES_AND_INSIGHTS.md` explains why the results matter and what they do not establish. It links to the reference tables instead of interrupting the explanation with them.

The edits apply the technical-writing and unslop skills. Technical terms remain where needed, with plain definitions. Instructions use direct verbs. Dense sentences are split, and hypothetical work stays separate from authorized work.
