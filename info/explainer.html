JEPA World Model over Longitudinal Glioma MRI — Runs & Experiments

Research repo explainer. Model: BRAINIAC ViT (LoRA) → clinical fusion → temporal transformer → predictor vs EMA target (JEPA). Data: LUMIERE, 91 glioblastoma patients, 65/13/13 split. Gate (proposal §6): beat persistence — a falling loss alone proves nothing.

0. Theses

T1 — encoder latent holds tumour state (RANO class, volume). Test = frozen probes. T2 — temporal latent predicts the future. Test = next-visit latent prediction vs persistence. T2's ceiling is T1's quality: dynamics over noise is hollow.

1. Training runs

Run 1 — INVALID (corrupt weights)

HF community BRAINIAC port. Loss fell (0.37→0.03) but target std 0.0024 / rank 1.1: constant-target collapse. Checkpoints deleted.

Why it matters: the founding lesson (I2) — monitors over loss. Every later run reports target std ≫ 0 and rank > 1 alongside loss.

Run 2 — pilot, official weights (CPU, 5 patients)

First valid run. A6 numbers: JEPA 0.0576 vs persistence 0.0043 (GRU 0.9993, clinical-only 1.0027). Learning signal proven (far below chance), persistence not beaten — expected at this scale.

Run 3 — extended 25-epoch pilot (CPU)

Best val 0.0093 (plateau from epoch ~13). A7: gap 13×→2.5×, first patient-level win (Patient-073: 0.0042 vs 0.0045). Verdict: epochs are spent, patients are the lever — motivates the full-cohort hero run, not longer pilots.

Run 4 — hero leg 1 (Kaggle T4, all 91 patients, 30 epochs, LR 1e-4)

Val: ep1 0.083 → ep5 0.0089 → ep~7 0.0081 → ep30 0.0704 (U-shape: optimum then steady overfit climb). Test 0.0074. A8: mean JEPA 0.0081 vs persistence 0.0218 (~2.7×, 82/91 wins, biggest on most dynamic patients) — the mandatory baseline falls. Engineering: batch 1 on 16 GB, chunked encoding, T4-only (P100 has no kernels), ingestion gunzips .nii.gz→.nii, torchao uninstalled.

Run 5 — hero leg 2 (resume best.pt, LR 2e-5, 30 epochs) — exploit FAILED

Val rose every epoch: 0.0089 → 0.031 plateau; leg best = epoch 1. D22 verdict: the epoch-7 optimum is a narrow basin unholdable by continued training (leg-1 tail ascended at decaying LR too — two schedules, same direction). Suspect: fresh optimizer discards basin-holding momentum. Engineering side-quest: two T4 OOMs → gradient checkpointing of prefixes (D21, then corrected: backbone chunks dominate) — verified bit-identical math.

Champion stands: best.pt, val 0.0081 / test 0.0074. No more 30-epoch legs.
