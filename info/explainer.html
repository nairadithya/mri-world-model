JEPA World Model over Longitudinal Glioma MRI — Team Explainer

We train a model to watch a brain-tumour patient's MRI history and predict the representation (a compact numeric summary) of the next visit — never pixels. Training data: LUMIERE, 91 glioblastoma patients (65 train / 13 val / 13 test). Held-out world: SAILOR, 27 patients from Oslo. Backbone: BRAINIAC vision transformer (frozen, tiny LoRA adapters) + clinical fusion + temporal transformer + predictor, trained against a slowly-trailing twin (EMA target). The one rule that governs everything: beat "predict no change" (persistence), measured in the same representation space on both sides (proposal §6; D28). A falling loss alone proves nothing; comparing across different spaces proved nothing either (we learned that one the hard way and corrected it).

Concept: collapse monitors. A model like this can cheat by mapping every scan to the same constant (great-looking loss, useless representation). Two monitors catch it: target spread (healthy when well above 0) and effective rank (healthy above 1). Every run below is judged on loss plus monitors plus persistence — all three.

1. Training story: six runs, one champion

Run 1 — invalid (corrupt weights, discarded) A2 · D8

A community re-upload of the backbone matched all 137 weight names yet produced near-identical outputs for MRI, pure noise, and zeros. Loss fell while monitors read sick throughout — constant-target collapse downstream of constant features. Checkpoints deleted. Standing rule: official weights only, verified by real-vs-noise behavior, never by key names.

Run 2 — pilot (5 patients, CPU): the loop learns D17 · A6

Loss 0.43 → 0.056 with healthy monitors — but dynamics 0.058 vs persistence 0.004. Learning proven, gate unreachable at this scale. Expected, not a redesign trigger.

Run 3 — extended pilot (25 epochs): epochs are spent A7

Best at ~epoch 13 (0.0093), then flat; first patient-level win, but the one held-out patient worst by far. Verdict: more patients, not more epochs — the argument for the full-cohort GPU run.

Run 4 — hero leg 1 (Kaggle GPU, all 91 patients): the champion D18 · D20 · D21 · A8 (+addendum)

Validation dives 0.083 → 0.0081 at epoch 7, then overfits steadily to 0.07 by epoch 30. Test: 0.0074. First clean beat of persistence on held-out patients — biggest on the most dynamic ones, losing only where "no change" is near-optimal. Practical rule: keep the best checkpoint, resume from the best, label every file with (leg, epoch, score) — a resume leg's file once overwrote the staged champion.

Run 5 — resume the champion gently: the optimum won't hold D22

Thirty more epochs at 5× lower learning rate: loss rises from epoch 1 (0.0089 → 0.031) and never touches 0.0081. Two schedules, same direction — the good spot is a narrow dip that continued training slides out of. Prime suspect: resuming discards the optimizer momentum that held it, and single-patient batches knock it out. Decision: no more long fine-tuning legs; the champion is final. (Later work refines this: with 8× accumulated batches the basin does hold — batch noise is part of the ejector. See §7.)

Run 6 — teach it the task directly: damaging without gain D25

Joint training with extra heads predicting next-visit response categories. Classification losses fell — but dynamics error more than doubled (0.0081 → 0.0191) while the honest task number didn't move (see §2). The single-split gain (0.45 → 0.51) was luck (see the CV box below). Verdict: tilted the encoder toward the exam without generalizable learning. Champion stands untouched; joint-from-scratch not earned. Same moral as the later multi-horizon leg: training the encoder tilts dynamics while frozen encoder + trained head preserves them.

Final model: first-leg best, val 0.0081 / test 0.0074 D20. All remaining work is evaluation with the encoder frozen. Basin-hold rerun A17 · D27 · D31: accumulated-8 batches hold the basin flat where batch-1 ejects — batch noise is part of the ejector; the loaded-optimizer half is untestable (opt-stripped ferries), with a recreate-then-ablate design parked in directions.md R11.

2. Honest probes: what the frozen champion actually knows D23 · A9 (+addenda)

Concept: hero-split vs cross-validation. One fixed test group (13 patients, 49 visits — with 1 partial-response and 2 complete-response cases) swings ±0.1 per patient. Our headline 0.45 sat above all five cross-validation folds (0.25–0.42, mean 0.33). The 0.45 was the lucky class, not the level. Rule: only the 5-way average counts; the single split is for debugging.
Concept: macro-F1 and the majority line. Labels are 64% progression, so always-guess-progression scores 65% accuracy while learning nothing. Per-class F1 balances precision ("when I say progression, am I right?") and recall ("what fraction do I catch?"); macro-F1 averages it equally across all four classes. The always-guess baseline sits ~0.20 — every plot shows it so 0.33/0.37 reads as real signal, not imbalance. Field best macro-F1: 0.50 (Tikhonov, supervised end-to-end + volumetry; TRACE 0.477); Matoso's 0.51 is balanced accuracy (median F1 0.13), a different metric D24. On the locked protocol ours is 0.309 CV / 0.408 transfer (A25).

Freeze the champion, train only a tiny readout. Single-visit features (F1 0.31) → history summaries (0.33) → forecast states predicting next visit's rating with no next-visit pixels in input (CV 0.33, lucky split 0.45). Response ratings are trajectory labels — useful only with time — and the temporal transformer beats raw visit-differences. Per class: progression recall 0.72, stable 0.64, the two rare classes noise by construction. Only forecast features need a nonlinear probe; current status reads linearly.

Volume (automated masks) A11: weakly readable (R² ≈ 0.15 — and plain regression without a ridge penalty explodes to R² ≈ −100 at 1152 features / 450 samples), next-visit size loses to "same as last visit." Surprise (prediction error → progression) A10 · A13 · D29: AUC 0.77 in-domain looks exciting until the trivial persistence-error baseline reaches 0.75 on identical pairs — and at two visits out, raw change (0.81) beats model surprise (0.70). Surprise is contemporaneous change-detection, not early warning. One genuine divergence: rare response transitions surprise our model most and persistence least — noticed as anomalous, not known as categories.

3. Cross-site: dynamics fail, representation transfers D26 · A12

The split that organized everything after: zero-shot dynamics lose ~5× (JEPA 0.029 vs persistence 0.006) while discriminative readouts transfer at full strength (F1 0.37 ≈ in-domain 0.33; surprise-AUC 0.87) with zero SAILOR training. Not interval (median gap 76d, persistence wins every bin), not disease (same protocol, near-identical survival) — the champion over-predicts change everywhere (flat ~0.03) on mostly-stable disease.

Per-gap accounting: persistence wins 7–14× in all four bins while the head sits flat. Same pairs, same space both sides — the interval excuse is dead and the mechanism is named: LUMIERE-calibrated stride on quieter trajectories.

Time-awareness helps, then stops helping

Concept: the gap-conditioned head. The champion's head is time-blind — same step for 7 or 200 days. The probe head takes history state (1152 numbers) plus one gap number, log1p(gap_days) standardized with training mean/std (log(1+x): compresses 1–1000+ days so long gaps stop shouting; the +1 keeps zero gaps finite at 0), through a small 1024×2 MLP. One state, many futures; near futures weighted 1/n. It beats the champion head 14–26% in every bin with error no longer flat — yet still loses to persistence 5–8×. Time was part of it; the residual sits below the head. Spending stopped here by pre-registered rule.

The rescue: refit only dynamics, on-site D30 · A15

Concept: the velocity field. Instead of predicting the endpoint in one shot, learn a rate of change and integrate it over the true day gap. Inputs per pair: running latent (current position, 768-d) + frozen history summary + treatment-phase id + clinical vector, through a small MLP; one learned per-patient tempo scalar stretches time. Three-step Euler: split the gap in thirds, step linearly, re-evaluate — so paths can curve. The last layer starts ×0.01, i.e. training begins at persistence and movement must be earned. That's the mirror image of the champion head, which emits fixed-scale steps unconditionally.

A tiny field fit on SAILOR (frozen encoder, subject-wise CV) beats persistence ~10% on held-out subjects where zero-shot lost 5×. The failure was dynamics scale — fixable on-site with 27 patients.

Treatment-phase vs constant-phase input: a pixel-perfect tie in 3 of 4 bins (and near-identical in the fourth), every fold, both model sizes. Given the 1152-d history state — which already encodes disease stage — the phase label is redundant. Not proof treatment is useless in principle; no operational gain at N=27. (LUMIERE couldn't even run this test — it has no treatment column.)

What the predictions still know A22

Concept: probing predictions instead of errors. Cosine error mixes up how far a prediction lands with what it still says. Instead, feed each method's predicted next-visit latent — and the actual next-visit latent — pair by pair into the same tiny RANO classifier, and compare what survives. One hygiene note that bit mid-run: cosine-trained heads emit arbitrary scales (gap-head vectors run ~5× larger than EMA vectors), and the unstandardized probe fit collapses on them — features are standardized with training statistics first, A9 protocol otherwise.

In-domain, predictions beat the thing predicted (CV 0.30/0.28/0.27 vs actual 0.25): the predictor carries the history summary, which knows more than the noisy snapshot — dynamics add signal, not just preserve it. The gap head matches targets far better (0.0039 vs 0.0075, beating persistence pooled) yet carries no more RANO signal than the champion head: matching the vector is not keeping its meaning.

Cross-site, the mirror image: the field has the best cosine error (0.0035, beats persistence) yet preserves less signal than the champion (0.32 vs 0.39 — it wins by shrinking toward persistence). Snapshot latents don't transfer at all (0.12–0.16); only history states do (0.37) — the transfer claim now has an address. And the SAILOR-fit field run backward onto LUMIERE fails symmetrically (0.0177 vs 0.0057) while still carrying gap-level signal (0.27): each site's dynamics die on the other's stride, in both directions. Error ratio and preserved signal dissociate both ways — a low JEPA error is not a representation-quality certificate.

4. The encoder is innocent (three independent exonerations) A16

Concept: site shift, PCA, PC1/PC2. Each visit is a point in 1152-d space; PCA finds the two widest viewing directions (PC1 34%, PC2 21% of variance — directions of spread, not clinical meanings). SAILOR forms one tight cluster apart from sprawling LUMIERE: a uniform shift (all 27 subjects moved together — scanners/protocol/processing, not bad apples). Uniform shifts preserve relative layout, which is why classifiers survive while step sizes don't. Note SAILOR's tightness — the damping story, visible before any model runs. (Plotted: per-visit fused latents, the space probes read; the dynamics' own target space separates even more strongly.)
Concept: CORAL. Correlation Alignment — closed-form linear fix: subtract the source mean, un-stretch the cloud to a ball along its own axes (whiten), re-stretch along the target's axes (recolor), shift to the target mean. No labels, no gradients; a small shrinkage term keeps dead directions from blowing up. It sits around the frozen predictor (aligning its inputs and targets into LUMIERE's frame), not after it — prediction still happens last.

Statistics-matching alone cuts head error 2.1× (0.0294 → 0.0140, A23-rebuilt field cache) with the encoder untouched, while persistence is preserved (geometry not distorted). About three-fifths of the failure was frame, not content.

Concept: transductive bound. Fit the map on all points including scored ones and you get 0.0081 — the floor for second-order matching, since it peeked at test statistics. Diagnostic only (no streaming deployment); the honest fold-wise 0.0140 is the claimable number. The 0.0081→0.004 remainder is what no covariance fix can reach.

The before/after pair is the story in one glance: shared frame afterward (same PC1 range), but SAILOR bands in the middle on PC2 — higher-order shape no linear fix touches. That's the residual, visualized. (Visualization fits on all visits; the scored number stays fold-wise honest.)

5. Preprocessing: the quieting is in the pipeline D3–D5 · A4 · D26 (recon) · A18 · A19 · A21

SAILOR's 11-step path (Rician denoise → intra-patient registration → PLHM longitudinal normalization → affine MNI → uint8) vs our contract (N4 → 1mm → per-visit rigid MNI → skull-strip → 96³+z-score). Shared: N4, 1mm, MNI-2009c family, skull-strip. Divergent: registration philosophy (opposite), longitudinal intensity handling (ours preserves visit differences; PLHM normalizes them away by design), resolution path (extra resampling generation). SAILOR's intra-patient step is the one piece that helps us (less jitter than our own floor).

Decisive measurement on identical pairs (243 linked pairs, raw tarballs extracted locally): raw change 0.673 vs MNI 0.173 — ~3.9× total pipeline damping, every modality (T1 most, T2 least at 2.6× with a heavy tail — T2 change survives processing best). Raw SAILOR sits at LUMIERE scale; the "quiet SAILOR" is made, not born. Scope held honestly: total pipeline effect (upper bound — raw carries position/skull signal registration legitimately removes), not PLHM-alone. Full protocol: src/preprocessing/; verification: scripts/raw_mni_deltas.py.

The decider: skull restored, gate still lost A19 · A21 · A23

Reprocessing SAILOR raw through our contract first failed to flip the gate and broke the readouts (F1 0.37 → 0.25) — the signature of a new confound, not a verdict. Audit found it: the skull-stripper can't run in our environment, so a dumb fallback left whole skulls in (half of every image vs one-sixth). Redoing only the skull-strip with the real tool in an isolated environment (scripts/bet_repair.py, QA drift 1.03×) decided it (numbers below are the A23 clean rebuild; see note):

Persistence wins every bin with the champion flat as ever — site, not skull. A23 (K3-1 content guard + cache rebuild) corrects A21: the earlier "readouts recovered 0.25 → 0.32" was computed but is not reproducible — rebuilding the betfix cache from the tree on disk gives a different result, and the old cache was overwritten and carried no provenance (K3-31). Rebuilt from the tree, skull-out transfer is 0.234, below the 0.479 majority and the weakest of the three arms, while the flagged ceiling<transfer anomaly resolves (ceiling 0.77 now above transfer): the fit path was never broken, the cache was. So skull restoration did not recover the readouts; it only restored derivatives-like features (four clouds) while the gate stays lost.

Four clouds, one glance: skull-out rejoins the derivatives neighborhood without approaching LUMIERE — stripping restored derivatives-like features (hence the F1 recovery) while the training site stays distant (hence the dynamics). No fundamental preprocessing lever remains for transfer (harmonizing further means degrading their better steps); the open preprocessing item is orthogonal — visit-consistent registration for LUMIERE's own noise floor.

6. The SOTA push: locked protocol, and every lever came back negative A25–A32

Before pushing for the field's number we fixed the yardstick. Locked protocol (info/eval_protocol.md): fixed patient-wise folds over the 26 encoder-unseen patients, a reserved 13-patient final slice touched once, and paired patient-cluster bootstrap CIs. Frozen champion: 0.309 within-unseen CV and 0.408 transfer; the readout seed alone spans 0.34–0.45, so the old single-split 0.45 was the lucky tail.

Then, each judged on that protocol:

  • Interface (A26). ROI/mask pooling (DeepBraTumIA), per-modality fusion, and explicit volumetry — none beat the whole-brain mean state; volumetry was significantly worse than the learned state. Spatial dilution is not the binding constraint.
  • Objective (A27/A28). Training the temporal stack on RANO overfits immediately (best dev at epoch 1); a properly tuned LoRA vision finetune (split head/rep LRs, augmentation, JEPA regularizer) did not improve the representation. Fourth and fifth confirmations that gradient on the representation tilts it.
  • Supervised comparator (A29–A31). Three from-scratch CNNs (3D visit-pair, 2D whole-brain slices, 2D tumor-ROI) all collapse to always-predict-PD in-domain (final 0.18–0.22) and lose to JEPA at every SAILOR K-shot point.

The picture: the value is the pretrained representation, not further training on 91 patients. A32 (reading Matoso 2025) sharpens it — our comparators were not faithful reproductions (under-trained, different preprocessing, no weighted sampler), but Matoso's own faithful best is weak (balanced accuracy 0.51, F1 0.13) and pretraining + clinical data hurt them too. The macro-F1 SOTA of 0.50 is carried by radiomics, not the CNN.

Bottom line. Frozen JEPA reaches ≈0.40 single-site RANO macro-F1 with zero task training and beats every from-scratch supervised model we could build, both in-domain and cross-site. Closing the remaining ~0.10 needs external longitudinal data or hand-engineered radiomics — not more LUMIERE gradient steps.

7. What it all means (for the team)

Representation travels; dynamics need local calibration. Nothing in the failure motivates unfreezing the encoder — every encoder change tried (task fine-tune, horizon leg) left honest metrics flat while costing dynamics. The three independent exonerations (on-site refit wins, statistics-matching recovers ~three-fifths, damping measured pre-encoder) converge: fix the frame and the stride, not the features.
Numbers to quote A8 corr · A9 · D24 · A10 · A13 · A11 · A12 · A15 · A18 · A21 · A22 · A23: dynamics gate (A24/K3-11): paired patient bootstrap — train pooled +0.0017 [0.0005,0.0031] = significantly WORSE than copying; test pooled −0.0017 [−0.0072,0.0012] not significant; only test patient-uniform −0.0086 [−0.0182,−0.0009] wins, on the selected aggregation, inflated by few-pair patients; wins 41/91 (45%) — so "beats persistence" is not established; RANO CV 0.33 (SOTA 0.50 = price of task-blindness); surprise = change-detection, no lead; volume R² 0.15, forecast loses; cross-site readouts transfer, dynamics need the site; pipeline damps ~3.9×; skull-out decider: gate still lost and (A23 rebuild) readouts did NOT recover — transfer F1 0.234, below majority; A21's 0.32 is not reproducible from the tree (cache provenance gap, K3-31). Gauntlet: predicted latents classify ≥ actual (LUM CV 0.30 vs 0.25; SAI CV 0.39 vs 0.33); error ratio and signal dissociate both ways. Only cross-validated numbers are headlines — every single-split number in this program was the lucky tail. Locked protocol (A25–A31): frozen 0.309 CV / 0.408 transfer; interface, temporal task-training, LoRA finetune, and three from-scratch CNN comparators all came back negative, and JEPA leads every cross-site K-shot point (cross_site_adapt.png).

8. What's next

  1. External longitudinal data (Step 5) — the only lever that adds information rather than re-weighting 91 patients: continue-pretrain on SAILOR plus other public cohorts, and make cross-site generalization the headline.
  2. Radiomics/growth comparator — done (A35). A 22-d volumetry+growth feature set (region log-volumes, log-growth, ratios, nadir-relative; DeepBraTumIA for LUMIERE, ONCO masks for SAILOR) reaches Tikhonov's volumes+growth ablation level (transfer final 0.41 vs their 0.45) but trails frozen JEPA everywhere (CV 0.217 vs 0.309; every SAILOR K). The remaining 0.50 gap is the full >4,800-feature radiomics + CatBoost, not a missing representation.
  3. Matoso portables (A32) — surgery-window pair exclusion (R7), augmentation inside SSL with an unaugmented EMA-target view, transition-balanced sampling (R13), a CT1-drop modality probe, and saliency-mask overlap.
  4. BraTS Task-11 submission (R20) — hidden-test numbers end split-luck debates permanently.
