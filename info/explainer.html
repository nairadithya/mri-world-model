JEPA World Model over Longitudinal Glioma MRI — Runs & Experiments

Model: BRAINIAC ViT (LoRA) → clinical fusion → temporal transformer → predictor vs EMA target (JEPA). Data: LUMIERE, 91 glioblastoma patients, 65/13/13 split; held-out: SAILOR, 27 patients. Gate (proposal §6): beat persistence, same representation space both sides — a falling loss alone proves nothing, and (learned 2026-09-07) mixed-space comparisons prove nothing either.

0. Theses

T1 — encoder/temporal latent holds tumour state (RANO class, volume). Test = frozen probes reading from the temporal latent (history summary), not snapshots: RANO is a trajectory statement. T2 — temporal latent predicts the future. Test = next-visit latent prediction vs persistence, same space. T2's ceiling is T1's quality.

1. Training runs

Run 1 — INVALID (corrupt weights)

HF community BRAINIAC port. Loss fell (0.37→0.03) but target std 0.0024 / rank 1.1: constant-target collapse. Checkpoints deleted. Lesson (I2): monitors over loss; behavioral weight checks mandatory (A2).

Run 2 — pilot, official weights (CPU, 5 patients)

A6: JEPA 0.0576 vs persistence 0.0043. Learning signal proven, persistence unbeaten — expected at this scale.

Run 3 — extended 25-epoch pilot (CPU)

Best val 0.0093 (plateau ~epoch 13). A7: gap 13×→2.5×, first patient win. Verdict: patients, not epochs.

Run 4 — hero leg 1 (Kaggle T4, 91 patients, 30 epochs, LR 1e-4)

Val U-shape: 0.083 → 0.0081 (~ep7) → 0.0704. Test 0.0074. A8 first reported 0.0081 vs 0.0218 (~2.7×, 82/91) — later corrected (A8 addendum): the 0.0218 was persistence in online-projector space while JEPA error lives in EMA-target space (3× wider consecutive drift). Same-space gate (scripts/split_gate.py): narrow patient-uniform win (0.0081 vs 0.0086), clear test win both aggregations (0.0070/0.0088 pooled, 0.0074/0.0160 patient-uniform). Gate cleared where it counts, thinly. Engineering: batch 1/16 GB, chunked + checkpointed encoding, T4-only, gunzip ingestion.

Run 5 — hero leg 2 (resume best.pt, LR 2e-5, 30 epochs) — exploit FAILED

Val rose every epoch (0.0089 → 0.031 plateau). D22: the optimum is a narrow basin unholdable by continued training (leg-1 tail agreed). Suspects: fresh optimizer discards basin-holding momentum (untested — checkpoints save opt state, resume ignores it: G8); batch-1 gradient noise (now testable via pair-weighted accumulation, D27).

Run 6 — aux fine-tune (champion + RANO heads, 10 epochs, LR 5e-6, λ=1.0) — RE-GATE FAILED

D25 design: flat/prog/resp heads, forecast framing, joint loss. Heads learned, no collapse, but JEPA val 0.0081→0.0205: dynamics paid 2.5×. Frozen re-probe: hero-split F1 0.51 (up) but CV 0.33±0.04 — unchanged. Verdict: tilted the encoder without generalizable gain; champion stands; joint-from-scratch not earned.

Champion stands: checkpoints/champion_0.0081.pt (val 0.0081 / test 0.0074). No more LUMIERE gradient steps without passing R11 first.

3. Multi-horizon program (closed)

Frozen-probe gate passed (beats persistence at every horizon; n=1 0.0050 beats the champion's own 1-step head 0.0074) → hero leg with gap-conditioned head + 1/n weighting earned → leg failed where it matters (n=1 0.0137 vs frozen 0.0050; far-horizon wins only) → re-gate identical downstream (RANO CV 0.323 vs 0.334, volume identical) → head-only sweep: small joint head is the ceiling. Verdict: frozen champion + small joint head is the production forecaster; no more GPU legs. Same moral as aux: training the encoder tilts dynamics, heads preserve them.

4. Cross-site (SAILOR) — failure localized, then partially rescued

A12: readouts transfer (F1 0.37 ≈ in-domain CV; surprise-AUC 0.87) while mean-error dynamics lose ~5×. Interval stratification ruled out the gap excuse (persistence wins every bin; median gap 76d vs LUMIERE ~90d — similar regimes); disease-mismatch exonerated (same Stupp GBM, OS 16.7 vs 19 mo); gap-conditioned head helped 15–20% but still lost 5–8×. Diagnosis: champion over-predicts change (flat ~0.03 at all gaps); LUMIERE-calibrated scale on mostly-stable disease.

A15 — site refit flips the gate: frozen champion + small velocity field fit on SAILOR (subject-wise CV, treatment vs constant-phase ablation) → held-out 0.0036 vs persistence 0.0040 (~10%), treatment adds nothing (exact tie both capacities). Transfer failure = dynamics scale, fixable on-site with N=27. A16 battery: site shift is uniform (probe AUC 0.9998) and largely second-order (CORAL alone cuts head error 2.4×, no training); damping is pre-encoder in image space (SAILOR |Δ| 0.24 vs LUMIERE 0.76, no overlap — PLHM prime suspect); within-phase tie rules out confounding-masking. Freezing exonerated three ways; full unfreeze not earned.
