JEPA World Model over Longitudinal Glioma MRI — Runs & Experiments

Model: BRAINIAC ViT (LoRA) → clinical fusion → temporal transformer → predictor vs EMA target (JEPA). Data: LUMIERE, 91 glioblastoma patients, 65/13/13 split. Gate (proposal §6): beat persistence — a falling loss alone proves nothing.

0. Theses

T1 — encoder/temporal latent holds tumour state (RANO class, volume). Test = frozen probes, reading from the temporal latent (history summary), not snapshots: RANO is a trajectory statement. T2 — temporal latent predicts the future. Test = next-visit latent prediction vs persistence. T2's ceiling is T1's quality.

1. Training runs

Run 1 — INVALID (corrupt weights)

HF community BRAINIAC port. Loss fell (0.37→0.03) but target std 0.0024 / rank 1.1: constant-target collapse. Checkpoints deleted. Lesson (I2): monitors over loss.

Run 2 — pilot, official weights (CPU, 5 patients)

A6: JEPA 0.0576 vs persistence 0.0043. Learning signal proven, persistence unbeaten — expected at this scale.

Run 3 — extended 25-epoch pilot (CPU)

Best val 0.0093 (plateau ~epoch 13). A7: gap 13×→2.5×, first patient win. Verdict: patients, not epochs — motivates the hero run.

Run 4 — hero leg 1 (Kaggle T4, 91 patients, 30 epochs, LR 1e-4)

Val U-shape: 0.083 → 0.0081 (~ep7) → 0.0704. Test 0.0074. A8: mean JEPA 0.0081 vs persistence 0.0218 (~2.7×, 82/91 wins, biggest on dynamic patients) — gate cleared. Engineering: batch 1/16 GB, chunked encoding, T4-only, gunzip ingestion, torchao removed.

Run 5 — hero leg 2 (resume best.pt, LR 2e-5, 30 epochs) — exploit FAILED

Val rose every epoch (0.0089 → 0.031 plateau). D22: the optimum is a narrow basin unholdable by continued training (leg-1 tail agreed). Suspect: fresh optimizer discards basin-holding momentum. Engineering: T4 OOMs → gradient checkpointing (D21, corrected: backbone chunks dominate), bit-identical math verified.

Run 6 — aux fine-tune (champion + RANO heads, 10 epochs, LR 5e-6, λ=1.0) — RE-GATE FAILED

D25 design: flat 4-class CE + prog (PD-vs-rest) + resp ((PR|CR)-vs-SD) heads on prefix states, forecast framing, joint loss. Heads learned (flat 3.08→0.37), no collapse, val total 1.89→1.69. But JEPA val 0.0081→0.0205 (test 0.0074→0.0174): dynamics paid 2.5×. Frozen re-probe: hero-split F1 0.51 (up) but CV 0.33±0.04 — unchanged. Verdict: tilted the encoder without generalizable gain; champion stands; joint-from-scratch not earned.

Champion stands: checkpoints/champion_0.0081.pt, val 0.0081 / test 0.0074. No more LUMIERE gradient steps.
